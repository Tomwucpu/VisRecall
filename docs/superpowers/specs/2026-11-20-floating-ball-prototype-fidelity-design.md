# VisRecall 悬浮球原型复刻方案

> 日期：2026-11-20  
> 状态：已实现（自动化测试通过；实机渲染与拖拽已验收，贴边/拖入实机待补）  
> 原型：`C:\Users\Tomwu\Downloads\code_artifact.html`（MonoDrop 极简黑白悬浮球）  
> 范围：重做原生悬浮球的视觉与交互动效，并接入拖放导入的进度反馈  
> 原则：不改变悬浮球的技术架构与产品入口语义；样式与动画向原型对齐，无法对齐的部分明确记录

## 1. 背景与目标

当前悬浮球是原生 Win32 分层窗口（`WS_EX_LAYERED` + `UpdateLayeredWindow`），由 GDI+ 在
`crates/shell/src/ball/mod.rs` 中直接绘制。它的功能完整（拖动、单击捕获、四边贴边收起、OLE 拖放、
全屏隐藏、位置记忆），但视觉仍是阶段 01 的占位样式：蓝色圆球 + 镜头图标 + 5px 细条。

原型提供了一套成型的极简黑白悬浮球设计，包含：

- 76% 不透明度的黑白玻璃球体与内高光；
- 拖动放大、贴边缩入为胶囊条、悬停弹性恢复；
- 拖入时的放大 + 旋转虚线光环 + 气泡提示；
- 导入进度环、完成对勾；
- 浅色/深色两套主题。

本次目标：

1. 在原生分层窗口内复刻原型的球体、贴边、拖动、拖入视觉与动画曲线。
2. 保留现有全部行为：单击触发截图、OLE 拖放、抓帧前隐藏、全屏隐藏、四边贴边、位置记忆、
   置顶不抢焦点、托盘开关。
3. 增加拖放导入的进度环与完成对勾，反馈由 app-core 回推。
4. 原型中的存储面板、灯箱、数量角标、Toast、透明度滑块不进入本轮范围（见 §8）。

## 2. 决策记录

| 决策 | 结论 | 原因 |
| --- | --- | --- |
| 技术路径 | 原生 GDI+ 重绘 | 保持低内存、OLE 拖放、抓帧隐藏的原生实现；不常驻 WebView |
| 单击行为 | 保持触发截图 | 截图是核心入口；原型的面板行为会让捕获入口只剩快捷键 |
| 贴边方向 | 保留四边 | 现有能力不回退；上下边按原型的胶囊形态镜像 |
| 反馈范围 | 球体 + 状态动画 + 导入进度/对勾 | 不引入面板、角标、Toast 等新窗口与图片绘制 |
| 主题来源 | 跟随 Windows 系统应用主题 | 主窗口可能不存在，前端 localStorage 主题不可依赖 |
| 默认尺寸 | 56，范围 50–150 | 设置页用滑动条实时调整；旧配置 40/48 加载时夹到 50 |

### 2.1 无法对齐的部分

原型毛玻璃依赖 CSS `backdrop-filter`。`UpdateLayeredWindow` 的逐像素 alpha 窗口无法透出并
模糊桌面内容，本轮用「半透明底色 + 顶部内高光」近似。76% 不透明度下观感差异较小，
但不承诺像素级一致。

## 3. 目标行为规格

### 3.1 几何与比例

所有视觉尺寸以原型 56px 为基准，按 `k = size / 56` 缩放，保证 50–150 连续尺寸下观感一致。

| 常量 | 原型值 | 实现值（size=56 时） |
| --- | --- | --- |
| 球径 | 56 | `size`（配置值） |
| 吸附阈值 | 64 | `round(64 * k)` |
| 胶囊厚度 | 10 | `round(10 * k)` |
| 胶囊长度 | 62 | `size + round(6 * k)` |
| 收起态命中留白 | 14 | `round(14 * k)` |
| 展开态距边缘 | 12 | `round(12 * k)` |
| 透明留白 | — | `round(14 * k)`（光环/放大/命中，不绘制阴影） |
| 气泡预留高度 | ~34 | `round(34 * k)`（仅拖入时扩展窗口） |
| 球体透明度 | 0.76 | 0.76；收起态 ×0.85 |
| 拖动放大 | 1.08 | 1.08 |
| 拖入放大 | 1.14 | 1.14 |

四边胶囊规则：

- 左：胶囊贴工作区左边，只圆右侧两角；指示线竖直。
- 右：胶囊贴工作区右边，只圆左侧两角；指示线竖直。
- 上：胶囊贴工作区上边，只圆下侧两角；指示线水平。
- 下：胶囊贴工作区下边，只圆上侧两角；指示线水平。

### 3.2 状态机时序

| 事件 | 行为 |
| --- | --- |
| 松手距工作区边缘 ≤ 阈值 | 吸附到该边，静置 800ms 后缩入胶囊 |
| 松手距边缘 > 阈值 | 恢复自由悬浮球形态，清空吸附锚点 |
| 鼠标进入胶囊热区 | **立即**展开为球形态，距边缘 12px |
| 鼠标离开展开态 | 800ms 后回缩；期间若再次进入则取消 |
| 鼠标位于热区时到收起时间 | 不收起 |
| 拖动中 / 拖入中 / 反馈播放中 | 不收起 |
| 全屏 / 演示 / 独占全屏 | 连续 3 次采样后隐藏，退出后按吸附状态恢复 |
| 抓帧会话 | 同步隐藏，会话结束恢复 |

现有状态机中的 `EXPAND_DELAY_MS = 150` 移除，改为 0（立即展开）；
`RETRACT_DELAY_MS` 由 600 调整为 800；`EDGE_SNAP_PX` 由 12 调整为 64。

### 3.3 动画

| 场景 | 曲线 / 时长 |
| --- | --- |
| 位置移动 | `cubic-bezier(0.22, 1, 0.36, 1)`，420ms |
| 球 ↔ 胶囊形变 | `cubic-bezier(0.34, 1.38, 0.64, 1)`，420ms |
| 拖动 / 拖入缩放 | `cubic-bezier(0.34, 1.45, 0.64, 1)`，340ms |
| 图标切换 | 透明度 220ms + 缩放 320ms（弹簧） |
| 指示线显隐 | 透明度 250ms + 缩放 320ms |
| 气泡显隐 | 透明度 200ms + 位移/缩放 250ms |
| 光环旋转 | 8s 线性无限 |
| 光环呼吸 | 1.6s ease-in-out 无限 |
| 完成对勾保持 | 720ms 后复位 |

拖动期间关闭过渡，窗口位置直接跟手；松手后再进入吸附/回缩动画。

### 3.5 图标

| 状态 | 图形 |
| --- | --- |
| 默认 | 圆角方框 + 十字（收纳意象） |
| 拖入可接受 | 向下箭头 + 底部横线 |
| 导入完成 | 对勾 |

图标以球心为锚，按 `k` 缩放；胶囊态淡出并缩到 0.35。

### 3.6 拖入反馈

- 可接受：球体放大 1.14、描边切换为前景色、外圈出现虚线光环（旋转 + 呼吸）、
  上方气泡显示 `DropVisual.label`，为空时回退「松开存入」。
- 不可接受：球体转灰，气泡显示拒绝原因（复用 `DropVisual.label`）。
- 拖入期间窗口向上扩展容纳气泡；气泡水平居中，超出屏幕时夹回可视区。
- 拖入结束、拖放完成或取消后恢复原尺寸与默认图标。

### 3.7 导入进度与完成反馈

| 阶段 | 显示 |
| --- | --- |
| OLE 收到 Drop | 立即显示不确定进度环（旋转弧），覆盖网络/落盘前的空窗 |
| 导入进行中，文件数已知 | 显示按 `done/total` 推进的环形进度，封顶 99% |
| 单项 / URL / 无总量信息 | 保持旋转弧 |
| 导入成功 | 对勾，720ms 后复位 |
| 导入失败 / 被闸门拒绝 | 短暂灰色环 600ms 后复位，不新增错误图标 |
| 捕获单击 | 不显示进度环（球随抓帧隐藏） |

## 4. 技术设计

### 4.1 窗口与动画驱动

新增 `crates/shell/src/ball/anim.rs`：

- 缓动函数：位移曲线、弹簧曲线、颜色/透明度线性插值。
- `VisualParams`：窗口矩形、四角圆角、球体缩放、球体透明度、图标状态与缩放、
  指示线显隐、进度值、气泡文案。
- `Animator`：保存 `from` / `to` / 起始时刻 / 时长，每帧产出 `VisualParams`；
  动画与光环运行期间启用 16ms 定时器（`TIMER_ANIM`），结束后停表。
  反馈复位使用独立定时器 `TIMER_FEEDBACK`（新增定时器 ID 3、4，现有 1 为状态截止、2 为全屏采样）。
- 所有插值均为纯函数，便于单测。

绘制与窗口更新继续走 `UpdateLayeredWindow`：它同时完成位置、尺寸与内容更新，
不需要额外的 `SetWindowPos`。

### 4.2 窗口矩形与命中测试

窗口矩形 = 视觉范围 + 透明留白；拖入时额外向上增加气泡高度。

- 自由态：`size × size` 四周加透明留白。
- 收起态：外侧固定在工作区边缘再向外扩命中留白，内侧加透明留白。
- 展开态（贴边）：窗口外侧仍锚定在 `工作区边缘 - 命中留白`，球体绘制在向内 12px 处。

最后一条是避免「展开→鼠标立刻在窗口外→回缩」抖动的关键：窗口不随球体内移，
鼠标停留在边缘区域时仍处于热区。

命中测试由 `WM_NCHITTEST` 完成：

- 自由态：球体圆形范围内返回 `HTCLIENT`。
- 收起态：胶囊矩形 + 14px 留白内返回 `HTCLIENT`。
- 其余透明区域返回 `HTTRANSPARENT`，点击穿透到桌面或其他窗口。

### 4.3 绘制

重做 `paint_ball`：

1. 清空为全透明，开启抗锯齿。
2. 绘制球体或胶囊（按四角圆角参数，不绘制投影）。
3. 绘制顶部内高光与 1px 描边。
4. 按状态绘制图标、指示线、进度环或对勾。
5. 拖入态绘制虚线光环与气泡。

进度环：背景轨道 2px、前景 2.2px、圆角端点；从 -90° 起按百分比扫过。
完成对勾用两段折线绘制。

气泡：圆角胶囊，使用主题前景色作底色、反色作文字；字体 `Microsoft YaHei UI`，
字号按 `k` 缩放；宽度自适应但不超过窗口宽度。

### 4.4 主题

通过系统「应用主题」判定浅色/深色（`ShouldSystemUseDarkMode`，失败时读注册表
`AppsUseLightTheme`），监听 `WM_SETTINGCHANGE` 后重绘。主题切换即时生效，不做渐变。

### 4.5 反馈接口与接线

新增可跨线程克隆的轻量句柄：

```rust
pub enum BallFeedback {
    Busy { progress: Option<u8> },
    Success,
    Failure,
}

pub struct BallFeedbackHandle { /* hwnd: Arc<AtomicIsize> */ }
```

`BallHandle` 暴露 `feedback_handle()`。实现通过 `PostMessageW` 发送
`WM_BALL_FEEDBACK`（`WM_APP + 12`），`wparam` 打包状态与进度；窗口不存在时静默忽略。

调用链：

```text
drop_target::Drop
  → ShellEvent::Drop
  → app-core 闸门检查
      ├─ 拒绝 → BallFeedback::Failure
      └─ 放行 → BallFeedback::Busy { progress: None } → spawn_import
                    → ImportFlow 逐文件进度 → Busy { progress: Some(pct) }
                    → 成功 → emit_created + Success
                    → 失败 → Failure
```

`crates/app-core/src/import_flow.rs` 增加带进度回调的入口：

```rust
pub fn ingest_with_progress(
    &self,
    content: DropContent,
    progress: &mut dyn FnMut(u32, u32),
) -> Result<Vec<Item>, AppError>;
```

原 `ingest` 保留，内部以空回调调用，避免影响现有调用点。`import_files` 每处理完一个文件
上报一次；文本/链接/位图等单次导入上报 `0/1` 与 `1/1`。

`spawn_capture_loop` / `handle_shell_event` 增加 `Option<BallFeedbackHandle>` 参数；
测试传 `None`。悬浮球线程在 OLE `Drop` 时也会立即进入 Busy，覆盖回推延迟。
`ShellEvent::DropRejected`（悬浮球线程在投递前已拒绝的载荷）同样回推 Failure。

## 8. 非目标

- 存储预览浮层面板与图片灯箱（原型单击球体打开；与截图入口冲突，且原生绘制缩略图成本高）。
- 数量角标（计数语义未定义）。
- 全局 Toast（原型底部提示）。
- 透明度滑块与对应设置项。
- 真实桌面毛玻璃。
- 前端主题与悬浮球主题联动（如需，另起方案）。

## 9. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 无真实模糊，观感有差异 | 提高内高光层次；在验收中确认可接受 |
| 逐帧 `UpdateLayeredWindow` CPU 占用 | 仅动画期间启用 16ms 定时器；实测超标则改为关键帧预渲染 |
| 透明留白挡住桌面点击 | `WM_NCHITTEST` 返回 `HTTRANSPARENT`；手测球体四周与胶囊外侧 |
| 拖入窗口扩展引起 OLE 事件抖动 | 窗口只扩展一次并在拖入结束时恢复；不在拖动过程中改变窗口层级 |
| 进度回调改动导入签名 | 保留原 `ingest`，新增入口；补齐回归测试 |
| 四边圆角方向易错 | 胶囊矩形与圆角规则抽成纯函数并单测 |

## 10. 后续可选

- 存储面板：若确有需求，建议评估独立的 Tauri 透明窗口承载，而不是原生绘制缩略图。
- 角标：先定义计数语义（如今日新增 / 待处理），再由 app-core 推送。
- 应用主题联动：主窗口启动时通过 IPC 下发解析后的主题，未启动时回退系统主题。

### 11.3 崩溃修复（2026-11-20）

- 现象：`thread 'visrecall-ball' panicked ... assertion failed: min <= max`，调用栈为
  `WM_TIMER` → 绘制 → `tooltip_rect`。
- 原因：拖入气泡的估算宽度可能超过当前窗口宽度（例如拒绝原因较长），
  `(center - width/2).clamp(work.x + 4, work.right() - width - 4)` 的上界小于下界。
- 修复：
  - 气泡宽度上限压到工作区宽度，`clamp` 上下界用 `max` 兜底；
  - 拖入时按气泡文案宽度横向扩展窗口，避免气泡被裁切；
  - 球/胶囊矩形在极小工作区下的 `clamp` 同样加 `max` 兜底。
- 回归测试：`tooltip_rect_survives_a_work_area_narrower_than_the_text`、
  `a_work_area_smaller_than_the_strip_does_not_panic`。
